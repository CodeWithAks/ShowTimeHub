# 🎬 ShowTimeHub

A movie discovery app built with React and TMDB API.

## Features
- Browse popular movies
- Search movies
- Filter by genre & rating
- Watch trailers
- Add movies to favourites
- Dark / Light mode

## Tech Stack
- React
- Vite
- Tailwind CSS
- Framer Motion
- TMDB API

## Future Improvements
- Backend with user authentication
- Persistent favourites
- Reviews & watch history
